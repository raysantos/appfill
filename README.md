# AppFill

A private, right-click Chrome extension that fills job applications from one profile, outlines what it can't answer, and keeps everything on your own computer.

- App page and download: https://raysantos.github.io/appfill/
- Case study: https://raysandesigns.com/appfill.html
- Extension source: [`extension/`](extension/) (install steps in [`extension/README.md`](extension/README.md))

Designed and built by Ray Santos.
